Document Summary Assistant

System Architecture, Technical Overview, & Limitations Report
Generated: August 2026 | Document Version: 1.0

1. Executive Overview & Theme

Document Summary Assistant is an AI-powered document processing and summarization platform. It ingests digital PDFs, scanned documents, and images, extracting textual contents using high-fidelity text layers or cloud-native multimodal vision OCR. It then outputs clean, structured Markdown summaries paired with key bullet points.

Core Design Principles:

  • Zero Local Binary Bloat: Eliminates OS-level dependencies (like Tesseract OCR installations), making cloud deployments seamless on platforms like Render or Vercel.
  • High-Speed AI Engine: Uses Groq REST API as primary inference provider for near-instant responses.
  • Resilient Dual Architecture: Automatic transparent fallback to Google Gemini 3 if primary quota or API limits occur.
  • Interactive Glassmorphic UX: Dynamic switching between Short, Medium, and Long summary formats.

Frontend UI React 18 + Vite, Vanilla CSS Single Page Application built with CSS design tokens, dynamic dark/light themes, and glassmorphic UI.

Primary LLM Groq API (Llama 3.3, Qwen 3.6, GPT-OSS) Ultra-low latency text summarization with dynamic model fallback selection.
Fallback LLM Google Gemini 3 (3.7-flash, 3.6-flash) Secondary LLM engine triggered automatically on Groq API errors or rate limits.
Deployment Render (API) & Vercel (UI) Cloud deployment configuration via environment variables.

3. Technical Limitations & System Constraints

Constraint Area Limitation Technical Details & Impact
Context Window 60,000 Characters Input text is truncated at 60k chars (~15k words). Large multi-chapter documents are truncated rather than processed via RAG.
Data Persistence Stateless In-Memory No database (SQL/NoSQL) or session storage. Reloading the frontend clears state.
Supported Formats PDF, PNG, JPG, JPEG, WEBP Plain text (.txt), Markdown (.md), or Word (.docx) files are not accepted without prior conversion.
API Key Dependency GROQ & GEMINI Keys OCR and summarization rely completely on external API availability and key provisioning.
Payload Size 50 MB Max Upload payloads strictly capped at 50MB to protect memory on free hosting tiers.
